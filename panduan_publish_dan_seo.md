Website siap upload: index.html, about.html, works.html, contact.html, assets/, styles.css, script.js, robots.txt.

## Publish gratis dengan Netlify (cara paling cepat)
1. Ekstrak ZIP website ini.
2. Buka https://app.netlify.com/drop lewat browser komputer.
3. Seret FOLDER `Muhammad_Nabil_Firdaus_SEO_Website` yang sudah diekstrak ke halaman Netlify Drop (bukan PDF atau ZIP). Jika perlu login, masuk dahulu.
4. Netlify menghasilkan URL publik. Ubah nama situsnya jadi misalnya `muhammad-nabil-firdaus` apabila tersedia.
5. Untuk reputasi profesional dan URL permanen, gunakan domain milik sendiri bila memungkinkan (contoh: `muhammadnabilfirdaus.com`, ini contoh dan belum dicek ketersediaannya).

## PENTING: ubah domain placeholder untuk structured data
Website memakai placeholder `https://YOUR-DOMAIN.example` dalam JSON-LD. Setelah mendapatkan URL final, lakukan Find & Replace pada keempat file HTML dan ganti ke URL final TANPA slash terakhir.

## Sitemap
Setelah domain final ada, buka `sitemap.template.xml`, ganti `https://YOUR-REAL-DOMAIN/` menjadi alamat situsmu, lalu simpan sebagai `sitemap.xml` dan upload versi baru. Isi `robots.txt` dengan `Sitemap: https://ALAMAT-SITUSMU/sitemap.xml` (hapus tanda #). Jangan kirim template bersisi placeholder sebagai sitemap.

## Daftarkan ke Google Search Console
1. Kunjungi https://search.google.com/search-console/
2. Tambahkan URL property situs (atau domain property dengan verifikasi DNS). Ikuti proses verifikasi yang diminta.
3. Setelah aktif, buka URL Inspection -> masukkan homepage -> Request Indexing.
4. Di menu Sitemaps, kirim `sitemap.xml` jika file sudah dibuat.
5. Periksa performa dari Google Search Console selama beberapa minggu berikutnya. Google tidak menjamin indeks atau posisi pencarian.
